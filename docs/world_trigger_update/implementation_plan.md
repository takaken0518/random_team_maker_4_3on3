# 実装計画書: update.md 対応（チーム数可変・参加者UI入力・ワールドトリガー風演出）

## 1. 対象要望（update.md）
1. チーム数を可変にする
2. 参加者入力をUIから行う（名前・使用キャラ入力 / CSV「名前,キャラ」読み込み）
3. 演出をサイバーパンク（ワールドトリガー風）にし、チーム決定演出の品質を上げる

## 2. 確認済みの仕様
| 項目 | 決定内容 |
|---|---|
| チーム数 | UIで指定。参加者を均等に割り振る（例: 20人÷6チーム → 4人×2 / 3人×4） |
| 参加者入力 | 名前・キャラ入力欄＋追加ボタン、一覧（編集・削除）、CSVファイル読み込み。テキストエリアは廃止 |
| 演出 | ランク戦風UI（六角形グリッド・シアン/グリーン・HUD枠）＋ チーム完成時の部隊エンブレム風カード演出 |

## 3. 変更内容
### ロジック
- `participants.js`
  - CSVの解析（BOM除去・ヘッダー行スキップ・UTF-8→Shift_JISの順で文字コードを判定）
  - プレイヤー生成、チームサイズ計算、チーム数バリデーション
- `draft-engine.js`
  - `initializeDraft(players, teamCount, mode)` で人数可変のスロットを生成
  - ラウンド順の場合、人数の少ないチームは最後の巡をスキップ
- `state.js`
  - `settings.teamCount` を追加
  - 旧バージョンの保存データは参加者だけ引き継いで移行

### UI / 演出
- `index.html` / `index.css`
  - 六角形グリッド背景、HUDコーナー枠、角を斜めに切った（チャンファー）パネル
  - シアン/グリーンの配色、チームごとのカラー
- `animation.js`
  - スキャンライン付きのルーレット
  - 文字がランダムに変化しながら確定する「デコード」演出
  - ロックオン照準と六角形の衝撃波
  - 部隊結成カード（エンブレムの線描画＋メンバーを順番に表示）
- `audio.js`
  - ロックオン音と部隊結成音を追加
- `app.js`
  - 参加者管理モーダル（追加・編集・削除・CSV）
  - チーム数の指定（±ボタン、割り振りのプレビュー表示）

## 4. 検証
- Node.js: CSV解析、均等割り振り、キュー生成、Undo
- ブラウザ: 実際に操作し、スクリーンショットで確認（**結果を受け取ってから報告する**）
