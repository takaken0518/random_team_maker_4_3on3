## 2. 実装ハイライトと特徴

### 2.1 配信映えするスマブラ風ステージデザイン
- **サイバー＆リッチUI**: ダークネイビー（`#0a0d14`）を基調に、スマブラゴールド（`#ffd700`）とフレイムレッド（`#ff334b`）の発光ネオンを採用。
- **イージング減速ルーレット**: 序盤は35ms間隔の超高速スピン、終盤はQuintic Ease-Outで徐々に減速（カチッ… カチッ… ドンッ！）。
- **Hitstop & Impactエフェクト**: 決定時に画面シェイク（`.screen-shake`）とホワイトアウト（フラッシュ衝撃波）が発火。
- **Canvas紙吹雪 & ファンファーレ**: 全24名（全チーム）確定時に紙吹雪が舞い散り、勝利のアルペジオ和音が鳴動。

### 2.2 外部依存ゼロ（Zero Dependency）の高安定性
- 音声ファイル読み込みエラーのリスクを排除するため、**Web Audio APIによる波形合成**でクリック音・風切り音・打撃クラッシュ・ファンファーレをリアルタイム生成。
- 外部CDNや重いライブラリを一切使わず、60fpsの描画パフォーマンスを維持。

### 2.3 OBS親和性 & フォールトトレランス
- **背景モード切替**: ワンクリックで「ダーク背景」「OBS透過背景」「ステージグラデーション」を瞬時に切り替え可能。
- **操作バー非表示トグル**: `H` キーを押すだけで下部操作バーが隠れ、OBSキャプチャ上でクリーンな配信専用レイアウトになります。
- **自動保存 (LocalStorage)**: 1人確定するごとに自動バックアップ。不意のブラウザ再読み込み（F5）でも直前の確定状態から再開できます。
- **Undo機能**: `Z` または `Ctrl+Z` で直前の抽選を即座に取り消し可能。

## 3. 動作検証結果

> [!WARNING]
> **訂正（2026-10-12）**: 初版では「ブラウザで24名の完走テストを実施した」と書いていましたが、誤りです。ブラウザでの確認は結果を受け取る前に報告しており、実施されていませんでした。
> 実際に確認したのは次の2点だけです。

1. **構文チェック**: `node -c` で全JSファイルにエラーがないことを確認。
2. **ロジック確認（Node.js）**: 24名のパース → 8チーム生成 → 1人抽選・確定 → Undoで元に戻る、までを確認。

未確認だった項目: ルーレット演出の表示、効果音、全員確定時の紙吹雪、背景切替、リロード後の復元。
→ 確認は後続のアップデート（[world_trigger_update](../world_trigger_update/walkthrough.md)）で実施します。

また、「Fisher-Yatesシャッフル」と書いた箇所がありますが、実装は `crypto.getRandomValues` で1人を選ぶ方式です。

## 4. 起動・利用方法

### 4.1 ワンクリック起動（Windows環境）
フォルダ内の **`start.bat`** をダブルクリックするだけで、ローカルサーバー（ポート3000）が起動し、ブラウザで自動的に表示されます。

またはターミナルから：
```bash
node server.js
```
ブラウザで `http://localhost:3000` にアクセスします。

### 4.2 キーボードショートカット一覧
- `Space`: 次の抽選を開始（ルーレット回転）
- `Z` または `Ctrl+Z`: 直前の抽選を取り消す（Undo）
- `H`: 操作コントロールバーの表示／非表示（配信画面キャプチャ用）
- `Esc`: モーダルを閉じる

### 4.3 OBS Studioでの取り込み設定
1. OBSのソース追加から **「ブラウザ」** を選択。
2. URLに `http://localhost:3000` を入力。
3. 幅: `1920`、高さ: `1080` を指定。
4. 画面下部の「📺 背景」ボタンを押し、**「OBS透過」** に設定することで、ゲーム画面や大会背景の上に綺麗に重ねて配信できます。
